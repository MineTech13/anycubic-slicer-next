Install

Install with your software center

Or from a terminal:

flatpak remote-add --user --if-not-exists anycubic-slicer @PAGES_URL@/anycubic-slicer.flatpakrepo
flatpak install --user anycubic-slicer @APP_ID@

The GNOME runtime is installed from Flathub automatically.

Updates

New Anycubic releases are built automatically. flatpak update, GNOME Software and Discover pick them up like any other app.

Already installed an earlier build?

Builds from this repo used to be called @LEGACY_APP_ID@. flatpak update moves them to @APP_ID@ automatically and keeps your settings.

Have someone else's Anycubic Slicer Flatpak with that same ID installed (e.g. a downloaded bundle)? It can stay installed alongside, or remove it:

flatpak uninstall @LEGACY_APP_ID@

Other downloads

AppImage and single-file .flatpak bundles are on the releases page. Source, troubleshooting and issues: github.com/@GH_REPO@.
